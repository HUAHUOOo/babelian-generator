# ATO Assistant 接入包

本目录是配套代码补丁，不会自动安装。巴别语独立版仍是仓库根目录的 `index.html`。

## 已准备的内容

- 独立模块：主控台入口、模块标签页识别、返回主控台。
- 故事书入口：从阅读页携带 `book/chapter/encounter/entry` 打开工具，并可返回来源段落。不读取正文、不自动破译图片、不修改剧情。
- `babelian` 存档分区：当前 ATO 账号下，按主控台的 `activeProfileId` 隔离工作。每个战役包含五个映射栏位及当前草稿；循环 4、5不被强制拆成两套字形对应。
- 正式保存通过现有 PHP/Android 接口，POST 带账号标识、战役标识及 `expectedRevision`。账号/战役在请求期间切换时，服务端拒绝写入。
- 同步失败保留按账号、战役区分的临时草稿；退出账号时仅保留这一专用命名空间的未同步草稿，不保留密码或登录令牌。其他账号不会通过本工具加载它。
- 主控台完整状态备份包含巴别语分区；完整备份导入在主控台分区导入后再恢复巴别语，使用版本检查。沿用主控台既有的分区导入机制，不保证所有分区在一个事务内回滚。
- Android：通过系统文件选择器保存 PNG 和 JSON；等待用户完成/取消后才报告结果，单个文件上限8MB。旧 APK 缺少桥接时会提示升级，不谎报下载成功。

## 构建

在巴别语生成器项目根目录运行：

```sh
node scripts/build.cjs
npm test
```

产物为 `dist/ato/babelian/index.html` 和 `dist/ato/babelian/assets/`。安装到辅助工具根目录的 `babelian/` 下；不要放在 `tools/` 或任何名为 `data` 的目录中，ATO 的打包脚本会排除这些目录。

## 应用配套补丁

`ato-assistant.patch` 基于 `10dbbf5`。`patch-baseline.json` 记录了7个源文件的校验值；补丁未包含个人存档、故事正文或图片。请先备份工程及 `data`，优先在副本或开发分支中操作。

在 **ATO Assistant 项目根目录** 运行，参数替换成这里的补丁文件路径：

```sh
git apply --check --ignore-space-change /path/to/ato-assistant.patch
git apply --ignore-space-change /path/to/ato-assistant.patch
```

检查失败时停下并人工合并，不使用强制覆盖。补丁是一次性的，已应用后再次执行检查会失败，这是正常的。补丁应用后，再把构建所得 `babelian/` 目录复制进去；若已有同名目录，先比较或备份，不直接覆盖已有工作。

修改范围：

| ATO 文件 | 改动 |
| --- | --- |
| `index.html` | 模块入口、完整备份导入导出、未同步草稿保留 |
| `assets/page-focus-router.js` | 在 dashboard 回退规则之前识别 babelian |
| `api/campaign-state.php` | 存档分区、默认值、版本及账号/战役检查 |
| `story/index.html` | 巴别语工具入口 |
| `story/assets/app.js` | 入口携带当前故事段落参数 |
| Android `LocalCampaignApi.java` | 对等的分区与账号/战役检查 |
| Android `MainActivity.java` | PNG/JSON 保存文件桥接 |

PHP 文件适用于网页、便携版、Docker；Java 文件仅在重新构建 APK 后生效。现有旧 APK 不会因为更改电脑端源码而自行更新。打包仍使用辅助工具自己的流程，无需引入新的运行框架或服务。

## 素材发布边界

`dist/ato/babelian/index.html` 只有代码与字形元数据，没有内嵌游戏图片。64张图片单独位于 `assets/`；遵守 ATO 项目的素材规则，仅在用户本地安装或按允许的方式提供素材包，不随公开代码提交。缺图时页面说明问题并停止编辑，不覆盖已有存档。

独立版和 `src/glyphs.json`、`src/parts.json` 仍包含原有用户提供的素材，不能把这些文件作为纯代码复制到 ATO 的公开仓库。打包成 Base64 并不改变素材本身。

## 迁移与冲突

- 单套映射：用原有“导出当前配置 / 导入到此栏位”。
- 五个栏位及草稿：用新增“下载完整工作备份 / 导入完整工作备份”。导入会确认替换当前工作，不自动混入其他账号的数据。
- 版本冲突：本机工作保留，自动同步暂停。先下载完整工作备份，再“重新读取存档”；不要直接覆盖其他页面的修改。需要恢复本机版本时，在最新存档基础上明确导入备份。
- 同步未完成时离开工具会先尝试保存，失败则提示处理；关闭页面会提醒。若未同步且用户清理浏览器全部数据、卸载 APK 或忽略关闭提示，任何本地临时草稿仍可能丢失，重要工作请及时导出。

## 验证情况与限制

适配器测试覆盖独立版存储键、账号/战役隔离、完整工作迁移、无效导入、版本冲突、断网重试、未同步草稿恢复和构建检查。接口测试使用模拟服务，不会向真实战役存档写入测试内容。补丁已针对指定本地版本执行 `git apply --check`，尚未实际安装到 ATO。

本次未构建 APK、未做安卓实机或真实 PHP 服务端联调。首次安装应使用测试账号/测试战役，验证完整存档备份恢复、同账号多页面冲突、手机PNG/JSON保存与取消、故事段落往返，再用于正式战役。
