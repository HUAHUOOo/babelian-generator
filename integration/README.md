1. 先在工具中下载完整工作备份，复制尚未保存的截图识别/整理文本；截图及逐字校正不会进入备份。
2. 更新本仓库，运行 `npm run build` 和 `npm test`。核对 `dist/ato/babelian/babelian-module.json` 的 `version` 为1.9.9。若有塞壬语工作，先单独保存生成及解读两种模式，并导出校正样本库；工作格式v6保存截图拟合、人工新增、朝向模式及锁定/复位记录，可读取v1–v5。旧项目默认自动朝向，旧默认大小迁移规则不变，v1截图解读需补标首交点。旧工具不能读取新v6文件。
3. 备份 Assistant 现有的 `babelian/` 目录；检查是否有个人代码改动，然后用构建产物更新模块 `index.html`、`assets/` 和 `babelian-module.json`。**不要覆盖 `data/`，不要把独立版根目录 `index.html` 当作接入版使用。**
4. 运行 `npm run check:ato -- "你的 ATO Assistant 根目录"`。此命令只读：检查宿主补丁状态、图片选择/联网代码和模块文件校验值，不读个人存档，不安装或修改文件。首次安装时会明确提示宿主补丁尚需应用，不能把“补丁可应用”理解成“已经安装”。
5. 网页/便携版按原流程重新打开模块。Android 需要用 Assistant 自己的打包流程重新生成 APK；仅复制电脑端文件不会更新手机上已安装的 APK。原打包器会注入 Android 网络桥接脚本，因此清单哈希用于**宿主打包前**校验，不用于比对打包器改写后的HTML。

源码与升级检查在本地 Assistant `10dbbf5` 上核对：已有 `onShowFileChooser` / 文件取消回调、`INTERNET` 权限，外部HTTPS请求由原生网络通道处理。机翻使用 HTTPS 并经用户明确同意，无须放宽明文网络策略或增加新的原生密钥。不同版本的宿主仍需检查；这些源码检查不等同于安卓实机联调。

## 已准备的内容

- 独立模块：主控台入口、模块标签页识别、返回主控台。
- 故事书入口：从阅读页携带 `book/chapter/encounter/entry` 打开工具，并可返回来源段落。不读取正文、不自动破译图片、不修改剧情。
- `babelian` 存档分区：当前 ATO 账号下，按主控台的 `activeProfileId` 隔离工作。每个战役包含五个映射栏位及当前草稿；循环 4、5不被强制拆成两套字形对应。
- 正式保存通过现有 PHP/Android 接口，POST 带账号标识、战役标识及 `expectedRevision`。账号/战役在请求期间切换时，服务端拒绝写入。
- 同步失败保留按账号、战役区分的临时草稿；退出账号时仅保留这一专用命名空间的未同步草稿，不保留密码或登录令牌。其他账号不会通过本工具加载它。
- 主控台完整状态备份包含巴别语分区；完整备份导入在主控台分区导入后再恢复巴别语，使用版本检查。沿用主控台既有的分区导入机制，不保证所有分区在一个事务内回滚。
- Android：通过系统文件选择器保存 PNG 和 JSON；等待用户完成/取消后才报告结果，单个文件上限8MB。旧 APK 缺少桥接时会提示升级，不谎报下载成功。

## 构建

在巴别语与塞壬语翻译器项目根目录运行：

```sh
node scripts/build.cjs
npm test
```

产物为 `dist/ato/babelian/index.html`、`dist/ato/babelian/assets/` 和 `dist/ato/babelian/babelian-module.json`。清单包含版本、功能和92个文件的SHA-256（页面+91张素材，含27张塞壬语素材），不含存档或个人路径。安装到辅助工具根目录的 `babelian/` 下；不要放在 `tools/` 或任何名为 `data` 的目录中，ATO 的打包脚本会排除这些目录。`dist/` 不提交到GitHub，从源码构建即可获得最新接入包。

本机自动匹配需要允许 Blob Worker（有CSP时配置相应的 `worker-src blob:`，不要放宽其他策略）；按钮粘贴依赖浏览器剪贴板许可，Ctrl+V及原文件选择入口保留。无需新增远程识别服务或账户权限。实际浏览器、Android宿主中的Worker/粘贴尚需实机验证。

## 应用配套补丁

`ato-assistant.patch` 基于 `10dbbf5`。`patch-baseline.json` 记录了7个源文件的校验值；补丁未包含个人存档、故事正文或图片。请先备份工程及 `data`，优先在副本或开发分支中操作。

在 **ATO Assistant 项目根目录** 运行，参数替换成这里的补丁文件路径：

```sh
git apply --check --ignore-space-change /path/to/ato-assistant.patch
git apply --ignore-space-change /path/to/ato-assistant.patch
```

检查失败时停下并人工合并，不使用强制覆盖。补丁是一次性的，已应用后再次执行检查会失败，这是正常的。补丁应用后，再把构建所得 `babelian/` 目录复制进去；若已有同名目录，先比较或备份，不直接覆盖已有工作。

修改范围：

| ATO 文件 | 改动 |
| --- | --- |
| `index.html` | 模块入口、完整备份导入导出、未同步草稿保留 |
| `assets/page-focus-router.js` | 在 dashboard 回退规则之前识别 babelian |
| `api/campaign-state.php` | 存档分区、默认值、版本及账号/战役检查 |
| `story/index.html` | 巴别语工具入口 |
| `story/assets/app.js` | 入口携带当前故事段落参数 |
| Android `LocalCampaignApi.java` | 对等的分区与账号/战役检查 |
| Android `MainActivity.java` | PNG/JSON 保存文件桥接 |

PHP 文件适用于网页、便携版、Docker；Java 文件仅在重新构建 APK 后生效。现有旧 APK 不会因为更改电脑端源码而自行更新。打包仍使用辅助工具自己的流程，无需引入新的运行框架或服务。

## 素材发布边界

`dist/ato/babelian/index.html` 只有代码与字形元数据，没有内嵌游戏图片。91张图片单独位于 `assets/`；遵守 ATO 项目的素材规则，仅在用户本地安装或按允许的方式提供素材包，不随公开代码提交。巴别语缺图时页面说明问题并停止编辑；若仅塞壬语缺图则只禁用塞壬语页签内的编辑，不覆盖已有存档。

独立版和 `src/glyphs.json`、`src/parts.json`、`src/siren-glyphs.json` 包含用户提供的素材，不能把这些文件作为纯代码复制到 ATO 的公开仓库。打包成 Base64 并不改变素材本身。

## 迁移与冲突

- 单套映射：用原有“导出当前配置 / 导入到此栏位”。
- 五个栏位及草稿：用新增“下载完整工作备份 / 导入完整工作备份”。导入会确认替换当前工作，不自动混入其他账号的数据。
- 版本冲突：本机工作保留，自动同步暂停。先下载完整工作备份，再“重新读取存档”；不要直接覆盖其他页面的修改。需要恢复本机版本时，在最新存档基础上明确导入备份。
- 同步未完成时离开工具会先尝试保存，失败则提示处理；关闭页面会提醒。若未同步且用户清理浏览器全部数据、卸载 APK 或忽略关闭提示，任何本地临时草稿仍可能丢失，重要工作请及时导出。

1.3.0 增加识别后的离线自动分词/推测句界。词频表和许可证内嵌模块HTML，不新增接口、密钥或存档字段。整理文本和补充词语仍是页面内临时数据；主动追加后的草稿按原规则保存。保留逐字英文，不根据分词结果修改OCR字母；尚未做本次浏览器交互、Android或真实ATO服务端到端验证。

1.4.0 增加指定识别项重新框选（仍然本机处理）和可选的英文→中文机翻。机翻在用户明确同意并点击后，通过 HTTPS 直接查询 `https://api.mymemory.translated.net/get`；不经过战役接口，不发送截图、映射、账号或密钥，不改变存档格式。英文采用当前手动整理版本，内容变化/过期会中止旧翻译并清除旧结果。译文不保存或同步。宿主需允许此域名的 HTTPS 查询及跨域连接；有 CSP 时需加入对应 `connect-src`，但不要放宽其他安全策略。未调整现有 ATO 工程或 Android 网络策略，未做真实宿主端到端验证。若外网受限，会提示失败，其他离线功能照常可用。

1.4.1 将重新框选升级为局部修复：新框覆盖本行前后原识别框面积严格超过20%时，固定新框，重新分割匹配本行局部两侧的剩余笔画，避免旧框重复输出。20%及以下保持其他项；跨行只提示。受影响项需要重新确认，外部的人工校正保持不变。失败不提交部分修改，映射、存档字段与接口不变。新增阈值、方向、完全覆盖、索引变化与实际字形素材合成图测试；未做浏览器/实机交互验证。

1.4.2 增加独立的笔画回收条件：旧框移出新框的实际笔画自动纳入本行邻近区域重识别，不受20%门槛限制；仅裁去空白不触发，缺少对应邻框时保留为新待确认项。新框像素不会重复计入邻框。机翻入口收纳到整理文本按钮栏，默认折叠，展开不发送数据；重新框选收纳在“分割不正确？”中，识别结果移动到逐字复核之后。存档及网络接口不变，新增逻辑与静态布局测试，未做实机/浏览器测试。

适配器测试覆盖独立版存储键、账号/战役隔离、完整工作迁移、无效导入、版本冲突、断网重试、未同步草稿恢复和构建检查。接口测试使用模拟服务，不会向真实战役存档写入测试内容。补丁已针对指定本地版本执行 `git apply --check`，尚未实际安装到 ATO。

本次未构建 APK、未做安卓实机或真实 PHP 服务端联调。首次安装应使用测试账号/测试战役，验证完整存档备份恢复、同账号多页面冲突、手机PNG/JSON保存与取消、故事段落往返，再用于正式战役。
