# 巴别语与塞壬语工具 · Babelian Generator

为桌游《Aeon Trespass: Odyssey》制作的非官方巴别语字形书写与映射工具。纯静态网页，书写、映射、截图识别和分词均可离线使用；可选的中文机翻需要联网，不需要自行配置密钥或服务器。

1.9.0 首页选择 **巴别语 / 塞壬语**，两个工作区分开显示。塞壬语支持粘贴截图、本机像素模板匹配、候选角度预览、删除误识别项及紫色人工叠加/原图覆盖度；不根据英文语义补字。精确参数增加联动滑块，字形朝向可切换自动/可调，手动角度不随位置变化。部分已知读序保留，未定位项单独提示但不禁用分词建议；数字词在整理结果中转换，例如 `fiftyfortyeight → 5048`，原始逐字英文不变。自由拖动、首交点排序、连续缩略图和整张PNG导出保留。操作及限制见 [塞壬语说明](SIREN.md)。巴别语映射、五个保存栏位和ATO战役存档格式不变。

1.9.0新增位置锁定/解锁、误拖复位和按需展开字形键盘；点选画布不自动滚动。复位保留手动改字，旧版已丢失拟合记录的项需重新匹配一次。说明文字精简，详细规则见塞壬语说明。

当前版本1.9.7：增加本机疑难字形深度比对和独立校正样本库，不调用在线识别。塞壬语键盘上排A→M、下排Z→N，相反旋向的对应字形同列；窄屏可横滑，仍保持两行。QQ20260911示例第一组V已由用户确认为朝向异常，不为补齐它放宽几何规则。深度候选需要人工确认，不保证比普通识别更准；测试边界见 [识别验证记录](integration/RECOGNITION_ACCURACY.md)。

1.9.6的高反差软笔画改进保留；该四组图仍可读出 `SEEN / TYNIN / ESIXT / YFIVE`，不根据已知答案补V。

### 疑难复核与校正样本（1.9.7）

- 巴别语：选中逐字复核项 → **疑难字形深度识别**，比较固定字形框内多个阈值和粗细尺度；候选只改变待选项，仍须点“确认使用此字形”。框分错时先校正分割。
- 塞壬语：进入截图模式，在已识别的组中点击 **疑难区域深度识别**；选中项会预填中心附近范围，也可在画布拖框。框只限定小螺旋中心，框外完整笔画仍用于匹配。点击候选预览紫色叠加，再点击 **采用所选候选**，替换所选项或新增一项，可撤销；不自动改动邻项。固定本组大螺旋，保留原角度、尺寸和边界约束。
- 校正样本：核实字形、位置后点 **已核实，加入样本库**。巴别语需先人工确认当前字形。展开样本库可改字形标注、备注、删除或取消“纳入后续训练”；朝向异常等样本可以只留档。
- 样本只在本页内存中，需单独**导出全部样本**留存；JSON可导入合并，冲突不会覆盖。每份最多100项、约7MB，保留原图裁片及定位；不进入映射备份或ATO战役存档，不自动上传、训练或立即提高下一张图准确率。收集后还需要另行评估、训练及独立测试。

1.9.5：巴别语改进紧密多行截图的行分割，根据完整字形匹配重新组合上下分离的笔画；无法匹配的宽扁碎片保留问号，不再中断整行。三张真实原图的206个首选字形保持全对，204项可确认，两处x与A+a的分割歧义保留；明显改进发生在缩小后的密行图片。1.9.6不改变巴别语算法。

1.9.4：塞壬语自动识别的最外参考线增加大螺旋宽度2.5%的径向余量；边界带与圈内分别保留候选起点，再按原有图形证据核验，避免新增候选挤掉圈内定位。反色样例第二组可纳入U并读出NTHOU，**不代表80字全对**。保留1.9.3的长条分窗、低对比反色处理及联合像素精调，仍是本机离线处理，不需安装后端。1.9.5未改变塞壬语算法。

定位符超出最外参考线及上述余量时仍直接忽略，不自动归入邻组；主候选与备选使用同一边界。没有手动框选、坐标和“将选区加入解读”，保留文件/粘贴/拖入及整图自动分割。旧存档和手动添加不被过滤，巴别语截图框选功能保留。新规则也不能保证不会漏项或误收邻组笔画，详见塞壬语说明。

## 直接使用

下载仓库后，用浏览器打开根目录的 `index.html` 即可，不需要安装开发依赖。

首次使用没有预填字形对应。进入“部件筛选与映射”，按六类楔形部件的准确数量筛选字形，设置它对应的字母、词语或符号。

- **QWERTY 键盘**：单个英文字母的映射会点亮相应键；未分配的按键灰显。
- **大小写独立**：A 与 a 分别设置。电脑键盘输入跟随 Caps Lock / Shift。
- **词语与符号**：非单个英文字母的对应显示在键盘下方，每次插入一枚字形。
- **冲突检查**：同一文本重复分配时显示两个字形，由使用者选择修改其中一个；不会直接覆盖。
- **58 个字形**：可按部件筛选、切换候选，也可浏览全部字形重新编辑。
- **5 个配置栏位**：支持部分映射、空白映射、命名保存、切换和 JSON 导入导出。
- **完整工作备份**：同时导入、导出五个栏位和书写草稿；导入前确认替换，不会与其他账号自动合并。
- **双行书写**：上方显示巴别语，下方显示英文；空格只在英文中占位。
- **撤销与导出**：保留已输入字形，修改映射时更新英文；支持撤销和 PNG 图片导出。
- **截图破解**：框选截图中的巴别语，按图形匹配58个模板，再使用当前自定义映射输出英文；提供候选复核与分割校正。
- **自动分词断句**：截图识别后自动生成带空格的英文建议，并可推测标点/句界；保留逐字原文，允许手动调整空格和标点。
- **中文机翻**：明确同意后，点击按钮翻译当前整理后的英文；采用手动调整的空格、换行和标点，不重新生成原文。英文变化即清除旧译文，避免过期结果。
- **重新框选字形**：移出旧框的实际笔画自动回收到本行邻近区域重新识别；覆盖其他识别框超过20%也会触发。固定新框，映射和其他区域不变。

未设置对应的字形可以从筛选页插入，英文暂以 `?` 占位。直接键入或粘贴时，只有已匹配的英文字母生成字形；词语与符号请使用对应按钮，不会根据语义自动合并。

## 数据保存与隐私

独立版的工作内容、映射和保存栏位存储在当前浏览器的 `localStorage` 中，不自动上传到服务器。浏览器、设备或网页地址改变后，保存的数据可能不共享；迁移前请导出备份。“导出当前配置”只包含当前字形对应；“下载完整工作备份”包含五个栏位和正在书写的段落。

**可选机翻例外**：勾选同意并点击翻译后，当前整理后的英文通过 HTTPS 发送给 MyMemory；不发送截图、映射、存档、账号、邮箱或密钥。输入/修改英文不自动发出请求。机翻来源含机器翻译及译文库匹配，适用该第三方的服务政策，请勿发送敏感内容。这里只调用查询接口 `/get`，不调用提交译文接口 `/set`，但不承诺查询不会被服务方记录。译文及英文快照仅留在页面内存，不进入存档或完整备份。

本仓库不包含用户个人保存配置、故事书、卡牌原图或剧情文档。旧版自动预填的默认表会迁移为空白，已命名保存的配置与自定义工作草稿保留；旧配置中的重复对应需要手动处理。

## 截图破解

1. 先载入要使用的映射配置，或在“部件筛选与映射”中设置字形的对应。空白配置仍可识别图形，但不能凭空得出英文。
2. 进入“截图破解”，选择、拖入或粘贴 PNG / JPG / WebP 图片（最多16MB）。拖动框选**仅包含巴别语**的区域，排除英文、标题、边框和插图；也可用像素坐标框选。优先使用端正、原尺寸的截图。
3. 点击“识别所选区域”。支持自动黑白方向/阈值、手动调整、单行识别和90°旋转。自动分行可以保留1–2像素的窄行距，只有完整像素形状明显优于碎片时才重组上下部件，避免把the、and等拆行。默认开启 **多尺度精细比对**，结合32×32与64×64的字形细节；模糊图也可能退步，可取消后重新识别对照，不会更改映射。上传后的单字墨迹高度不足30像素时仍保守标记为待确认；模糊照片、倾斜、多栏和相连文字建议分段裁剪。
4. 结果按原图行序输出。`[?]` 表示图形或分割不确定；`[未映射]` 表示已识别的字形尚无对应。相似度是图形评分，**不是正确率保证**；绿色自动匹配项也需要核对。
5. 点击分割项或原图识别框，对照原图裁片与候选模板。可从全部58个字形手动选择、确认，或重新标为待确认。分割错误时可按比例拆分一个框或与本行下一框合并，然后重新确认。
6. 切换、编辑、导入或撤销映射时，识别英文实时更新，字形识别本身不变。可复制逐字英文、合并原图换行，或**追加**到书写区（不覆盖已有内容，可撤销）。原图字距不被当作英文词间空格。
7. 默认开启“识别后自动分词断句”：另行显示可编辑的整理文本。会接续跨原图行尾的单词，按离线英文词频和ATO术语尝试分词；“推测标点与句界”可单独关闭。上方逐字原文一直保留，复制/追加逐字原文与整理文本是两个独立操作。
8. 自动分词或规则推测的句界可能出错，**不是故事书原标点的恢复保证**。专名分错时可补充分词词语；该输入仅影响本次整理，不改变映射。可以手动调整空格和标点，但不允许修改字母、大小写、数字、原有标点或 `[?]` / `[未映射]` 占位符。若字形认错，请返回逐字复核。
9. 已手动调整的整理文本，不会被随后的映射/识别修改静默覆盖。页面会保留编辑并标记过期，暂停复制/追加，需点击“重新生成建议”并确认。追加整理文本保留识别字形的顺序及标识，空格不额外生成巴别语字形。

### 在截图中校正单个字形框

页面按“截图 → 逐字复核 → 识别结果”排列，逐字英文、整理英文及机翻位于最下方。点击需要校正的识别项 → 展开 **分割不正确？** → **在截图中重新框选此字形**（位于拆分、合并按钮之后）→ 在原识别区域（金色框）内拖出完整字形 → **应用新框** → 复核并确认候选。拖动过程中不清空整页结果；可以重新拖动或按 Esc / 取消恢复原框。超出原识别区域或框内无笔画时拒绝替换；要使用区域外像素，需要扩大主区域重新识别。

有两种独立的局部重匹配触发条件：

- 旧框内原有的实际笔画不再位于新框中：不受20%门槛限制，自动纳入本行左/右邻近识别区域。只移出空白不触发。上/下移出的笔画按较近的水平侧分配；行首/行尾缺少相应邻框时保留为新待确认项，不丢弃。已属于其他框的排除区域不会当作旧框笔画再次回收。
- 新框与**本行前后原识别框**的重叠面积占该原框面积严格**大于20%**：按 `相交面积 ÷ 该原识别框面积` 计算，正好20%不满足这项条件。所有现有分割项（包括待确认项）参与几何检查；其他行不重新识别。

两项条件均不满足时只替换当前项。邻近重识别使用当前图像与字形模板，不以英文语义猜字。

触发后，以选中项、被覆盖项及接收移出笔画的邻近项构成连续局部区域，将新框锁定为一个字形，重新分割两侧剩余笔画并匹配模板。完全被新框吸收的旧框不重复输出；局部项数可增减。新框像素在邻近识别中被排除，后续复核裁片、拆分/合并也保留此像素归属；若裁片隐去其他框已分配的区域会明确标注。最近未受影响的原框是外边界，外部人工确认与其他行保持不变。应用后显示旧项/新项数量，选择仍跟随新框，受影响候选需重新确认；映射不变。失败时整次替换不生效，旧结果保留。

### 翻译整理后的英文

1. 在“整理后的英文”中完成分词、断句和标点调整；原文字母识别错误时先回到复核项修改。
2. 点击“复制整理文本”“将整理文本追加到书写区”旁的 **中文机翻** 按钮展开面板。展开本身不联网；勾选同意后，点击 **将当前英文翻译为中文** 才发送。以此刻文本框内容为准，不调用自动整理覆盖手动编辑；可展开查看本次英文快照。再次点击入口可收起，正在翻译时收起会中止后续请求。
3. 译文显示在单独的中文文本框，可复制。`[?]` / `[未映射]` 保留，不让翻译服务猜字。机翻不会改写逐字英文、整理英文、字形或配置，游戏专名及规则需人工核对。
4. 翻译中或完成后修改英文、变更底层识别/映射导致整理文本过期、清除截图、取消翻译或撤回同意，都会使旧结果失效。已发送的请求无法撤回，但未发出的后续分段会停止，过期响应不会显示。
5. 每次最多5000字符，按句界/空白优先分段，每段不超过480个 UTF-8 字节（服务上限500字节）。长段落存在跨段上下文损失；页面会显示进度，错误、超时或额度不足时不把部分结果当作完整译文。

使用 [MyMemory 官方查询接口](https://mymemory.translated.net/doc/spec.php)，方向为 `en|zh-CN`、开启 `mt`。免费额度、可用性和译文质量由服务方决定；浏览器或 Android 宿主若限制外网/跨域会显示连接错误。不开启机翻不影响离线功能。开发中仅用无私人信息的普通测试句验证了接口返回中文及跨域响应头，未做浏览器或安卓真实联网操作验证。

字形识别阶段是本机的模板匹配、图像二值化与动态分割，不使用词频或语义反推字母，没有默认答案表或在线OCR接口。自动分词是识别之后的独立建议层：只插入空格和推测标点，不会利用词典填补未知字形。截图、识别结果、逐字校正、整理草稿和补充词语默认只保存在当前页面内存，刷新后清除，**不包含在完整工作备份中**；可选机翻仅发送当前整理英文。只有主动“追加到书写区”的文字/字形进入原有草稿保存流程；ATO模式下这份草稿按原有账号与战役同步，截图不会上传。清除截图不影响映射和书写内容。

新增功能沿用独立版和ATO接入版构建，不需要额外服务器或安装识别依赖。Android宿主仍需要支持标准网页图片文件选择；原生设备文件选择、浏览器交互和真实ATO环境尚未进行本次端到端验证。

## 开发与构建

构建只需 Node.js 20 或以上版本，不依赖 Python、外部字体或图片服务：

```sh
node scripts/build.cjs
```

修改 `src/template.html`、`src/mapping-editor.js` 或平台适配代码后重新构建，得到两种模式：

- `index.html`：独立版，图片内嵌、无需登录、无需接口，保留原有本地存储键。
- `dist/ato/babelian/`：ATO 接入模块，图片拆分在 `assets/` 下，需要辅助工具的配套存档接口。构建模式固定，不通过任意网址参数猜测是否启用账号同步。

两种模式共用核心逻辑，不需要维护两份键盘或解密算法。构建不会连接 GitHub、上传文件、安装模块或改动 ATO 工程。

主要文件：

| 文件 | 内容 |
| --- | --- |
| `index.html` | 可直接打开的完整网页 |
| `src/template.html` | 页面布局、样式与书写逻辑 |
| `src/mapping-editor.js` | 字形筛选、映射、冲突检查与配置管理 |
| `src/runtime.js` | 独立/ATO 保存适配、账号与战役隔离、冲突与临时草稿恢复 |
| `src/host-ui.js` | 模式状态、完整工作备份、主控台/段落导航、Android 文件桥接 |

| `src/ocr-correction.js` | 重画识别框的坐标校验、20%覆盖判断、锚定新框的局部分割匹配 |
| `src/translation.js` | 可选文本翻译、按字节分段、超时/取消与过期响应保护 |

## 接入 ATO Assistant

请阅读 [接入说明](integration/README.md)。配套补丁针对本地检查过的 `banard2049-cpu/ATO_assistant` 的 `10dbbf5` 版本；安装前必须先检查能否应用，不要强制覆盖新版本代码。

最新1.9.6接入包包含巴别语多尺度比对、模板辅助行分割、塞壬语软笔画处理、整组像素核验和高分辨率裁片，并保留整图识别、最外圈过滤（含2.5%余量）、删除/紫色人工叠加、参数滑块、自动/手动朝向及数字词显示。构建会生成 `dist/ato/babelian/babelian-module.json`，记录版本、素材及页面校验值。已接入1.1.0及之后版本时只需更新模块，无须重复安装宿主补丁或迁移战役存档。塞壬语工作仅在页面内存，须单独导出JSON；v6工作保存朝向模式、锁定状态与复位记录，可读取v1–v5，不写入战役存档。运行 `npm run check:ato -- "ATO Assistant 根目录"` 可执行只读兼容性检查；具体升级及Android重新打包步骤见接入说明。

接入版使用当前 ATO 账号与主控台战役标识保存五个栏位、当前映射、草稿及故事段落来源。保存需要接口返回成功才显示“已同步”。断网时保留按账号/战役区分的临时草稿，允许重试；账号、战役切换或版本冲突时暂停自动写入，可先导出完整工作备份，再重新读取存档。不会自动读取或上传独立版的本机配置。

网页接入、Windows/macOS/Docker 接入沿用现有 PHP 接口；Android APK 通过项目已有的原生接口，并需要配套补丁中的 Java 存档与文件导出适配。未安装接口或缺少素材时，接入版明确提示并停用编辑区，不悄悄降级为独立存档。

## 素材说明

自动分词使用 [Wordninja 的英文词频表](https://github.com/keredson/wordninja)，按其 MIT 许可保留完整声明于 `src/wordninja-LICENSE.txt`，独立版及ATO版HTML也内嵌该声明。来源提交和SHA-256记录在 `src/english-words-source.json`；构建校验本地数据并内嵌词表，不联网下载。没有导入上游Python可执行代码；分词、原文保护及句界建议由本项目的独立JavaScript模块实现。该词频数据许可与下述游戏图形素材权利分开。

58 个字形与 6 类部件已换用新提供的高清截图素材。字形按原始像素提取，高度约 195–202 像素，保留透明背景与抗锯齿边缘；没有重绘或对旧图进行插值放大。页面按原有显示尺寸缩放，字形编号、部件数量和保存配置格式不变。构建直接使用 `src/glyphs.json`、`src/parts.json`，无需原始截图。

这是非官方爱好者辅助工具，与游戏发行方无隶属关系。游戏名称和相关字形素材的权利归各自权利人所有。本仓库不为第三方素材授予额外使用许可。
