# 巴别语与塞壬语工具 · Babelian Generator

《Aeon Trespass: Odyssey》的非官方密码辅助工具：用字形书写、识别截图、复核字母，并整理成英文或翻译为中文。生成与识别可离线使用，中文机翻为可选联网功能。

## 快速开始

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 用浏览器打开文件夹中的 `index.html`，无需安装程序、注册账号或配置服务器。
3. 在首页选择 **巴别语** 或 **塞壬语**，按下面的步骤开始。

### 巴别语：先设置对应，再书写或识别

首次打开时键盘为空，这是正常的：工具不会预填字形答案。

1. 进入 **部件筛选与映射**，按楔形部件数量找字形，设置对应的字母、词语或符号。大小写分别设置；也可以导入已有配置。
2. **书写**：点击字形键盘或使用电脑键盘输入，上方显示巴别语、下方显示英文。空格只出现在英文中，不增加字形间距。
3. **识别截图**：进入 **截图破解**，选择、粘贴或拖入图片，框住巴别语区域，点击 **识别所选区域**。识别出的字形按当前映射转成英文。
4. 点击结果逐字复核；分割不对时可拆分、合并或重新框选。确认后复制英文，或追加到书写区。

映射支持5个保存栏位。识别后可生成分词断句建议，调整空格和标点，再按需使用中文机翻。

### 塞壬语：生成螺旋或识别截图

- **生成**：选择 **字母 → 螺旋**，添加大螺旋，再点击 **新增其他小螺旋** 展开字形键盘。每组最多6个字母，可拖动调整位置，也可批量生成。
- **识别**：选择 **截图 → 识别与复核**，粘贴或选择图片，点击 **自动分割并匹配**。
- **复核**：选中小螺旋，对照原图与候选字形。需要时使用 **精确调节**、锁定位置或删除误识别项。
- **导出**：生成的螺旋可导出整幅PNG；英文可复制、生成分词断句建议或机翻。

字母按从大螺旋中心向外最先遇到的笔画交点排序；每个大螺旋不一定是一个完整单词。

## 识别不准时怎么办？

优先使用清晰、端正、只含密码文字的图片，尽量避开标题、插画和英文说明。

- `[?]` 表示需要复核；巴别语的 `[未映射]` 表示该字形还没有设置英文对应。
- 可以使用 **疑难字形深度识别**（巴别语）或 **疑难区域深度识别**（塞壬语）多比较一轮，再手动确认候选。
- 匹配分数不是正确率。工具不会按词义补齐未知字母，分词和机翻也需要核对。
- 核实后的字形可以加入 **校正样本库**，方便留存与后续改进；目前不会自动训练或立即改变识别结果。

## 保存与隐私

刷新或关闭前请留意：以下内容使用不同的保存方式。

| 内容 | 保存方式 |
| --- | --- |
| 巴别语映射与书写草稿 | 独立版保存在当前浏览器；用 **下载完整工作备份** 导出。换浏览器、设备或文件地址前请备份。 |
| 巴别语截图识别结果 | 不在完整工作备份中；需要的英文请复制，或追加到书写区后保存。 |
| 塞壬语画布与截图解读 | 在生成、解读模式下分别点击 **保存塞壬语工作**。整理英文和译文请另外复制。 |
| 校正样本库 | 单独点击 **导出全部样本**，以后可导入继续使用。 |

截图识别在本机完成，不上传图片。只有同意并主动点击中文机翻时，当前整理后的英文才会发送给 MyMemory；采用你调整后的空格和标点。机翻为第三方服务，请勿发送敏感内容。
