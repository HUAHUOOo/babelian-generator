# 巴别语生成器 · Babelian Generator

为桌游《Aeon Trespass: Odyssey》制作的非官方巴别语字形书写与映射工具。纯静态网页，无需账号、服务器或在线接口，可离线使用。

## 直接使用

下载仓库后，用浏览器打开根目录的 `index.html` 即可，不需要安装开发依赖。

首次使用没有预填字形对应。进入“部件筛选与映射”，按六类楔形部件的准确数量筛选字形，设置它对应的字母、词语或符号。

- **QWERTY 键盘**：单个英文字母的映射会点亮相应键；未分配的按键灰显。
- **大小写独立**：A 与 a 分别设置。电脑键盘输入跟随 Caps Lock / Shift。
- **词语与符号**：非单个英文字母的对应显示在键盘下方，每次插入一枚字形。
- **冲突检查**：同一文本重复分配时显示两个字形，由使用者选择修改其中一个；不会直接覆盖。
- **58 个字形**：可按部件筛选、切换候选，也可浏览全部字形重新编辑。
- **5 个配置栏位**：支持部分映射、空白映射、命名保存、切换和 JSON 导入导出。
- **双行书写**：上方显示巴别语，下方显示英文；空格只在英文中占位。
- **撤销与导出**：保留已输入字形，修改映射时更新英文；支持撤销和 PNG 图片导出。

未设置对应的字形可以从筛选页插入，英文暂以 `?` 占位。直接键入或粘贴时，只有已匹配的英文字母生成字形；词语与符号请使用对应按钮，不会根据语义自动合并。

## 数据保存与隐私

工作内容、映射和保存栏位存储在当前浏览器的 `localStorage` 中，不上传到服务器。浏览器、设备或网页地址改变后，保存的数据可能不共享；迁移前请导出 JSON 配置备份。JSON 配置只包含字形对应，不包含正在书写的段落。

本仓库不包含用户个人保存配置、故事书、卡牌原图或剧情文档。旧版自动预填的默认表会迁移为空白，已命名保存的配置与自定义工作草稿保留；旧配置中的重复对应需要手动处理。

## 开发与构建

构建只需 Node.js 20 或以上版本，不依赖 Python、外部字体或图片服务：

```sh
node scripts/build.cjs
```

修改 `src/template.html` 或 `src/mapping-editor.js` 后重新构建，即可得到包含全部字形图片的单文件 `index.html`。

主要文件：

| 文件 | 内容 |
| --- | --- |
| `index.html` | 可直接打开的完整网页 |
| `src/template.html` | 页面布局、样式与书写逻辑 |
| `src/mapping-editor.js` | 字形筛选、映射、冲突检查与配置管理 |
| `src/glyphs.json` | 内置字形图像数据 |
| `src/parts.json` | 六类部件图像和各字形部件数量 |
| `scripts/build.cjs` | 单文件网页构建脚本 |
| `tests/smoke.cjs` | 功能及响应式布局测试 |

运行测试：

```sh
npm install
npx playwright install chromium
npm test
```

也可通过环境变量 `BROWSER_EXECUTABLE` 指定本地 Chrome / Chromium 可执行文件。测试使用独立临时浏览器，不读取日常浏览器中的个人配置；测试截图写入 `tests/qa/`，不会纳入 Git。
