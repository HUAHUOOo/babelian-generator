# 巴别语生成器 · Babelian Generator

为桌游《Aeon Trespass: Odyssey》制作的非官方巴别语字形书写与映射工具。纯静态网页，无需账号、服务器或在线接口，可离线使用。

## 直接使用

下载仓库后，用浏览器打开根目录的 `index.html` 即可，不需要安装开发依赖。

首次使用没有预填字形对应。进入“部件筛选与映射”，按六类楔形部件的准确数量筛选字形，设置它对应的字母、词语或符号。

- **QWERTY 键盘**：单个英文字母的映射会点亮相应键；未分配的按键灰显。
- **大小写独立**：A 与 a 分别设置。电脑键盘输入跟随 Caps Lock / Shift。
- **词语与符号**：非单个英文字母的对应显示在键盘下方，每次插入一枚字形。
- **冲突检查**：同一文本重复分配时显示两个字形，由使用者选择修改其中一个；不会直接覆盖。
- **58 个字形**：可按部件筛选、切换候选，也可浏览全部字形重新编辑。
- **5 个配置栏位**：支持部分映射、空白映射、命名保存、切换和 JSON 导入导出。
- **完整工作备份**：同时导入、导出五个栏位和书写草稿；导入前确认替换，不会与其他账号自动合并。
- **双行书写**：上方显示巴别语，下方显示英文；空格只在英文中占位。
- **撤销与导出**：保留已输入字形，修改映射时更新英文；支持撤销和 PNG 图片导出。

未设置对应的字形可以从筛选页插入，英文暂以 `?` 占位。直接键入或粘贴时，只有已匹配的英文字母生成字形；词语与符号请使用对应按钮，不会根据语义自动合并。

## 数据保存与隐私

独立版的工作内容、映射和保存栏位存储在当前浏览器的 `localStorage` 中，不上传到服务器。浏览器、设备或网页地址改变后，保存的数据可能不共享；迁移前请导出备份。“导出当前配置”只包含当前字形对应；“下载完整工作备份”包含五个栏位和正在书写的段落。

本仓库不包含用户个人保存配置、故事书、卡牌原图或剧情文档。旧版自动预填的默认表会迁移为空白，已命名保存的配置与自定义工作草稿保留；旧配置中的重复对应需要手动处理。

## 开发与构建

构建只需 Node.js 20 或以上版本，不依赖 Python、外部字体或图片服务：

```sh
node scripts/build.cjs
```

修改 `src/template.html`、`src/mapping-editor.js` 或平台适配代码后重新构建，得到两种模式：

- `index.html`：独立版，图片内嵌、无需登录、无需接口，保留原有本地存储键。
- `dist/ato/babelian/`：ATO 接入模块，图片拆分在 `assets/` 下，需要辅助工具的配套存档接口。构建模式固定，不通过任意网址参数猜测是否启用账号同步。

两种模式共用核心逻辑，不需要维护两份键盘或解密算法。构建不会连接 GitHub、上传文件、安装模块或改动 ATO 工程。

主要文件：

| 文件 | 内容 |
| --- | --- |
| `index.html` | 可直接打开的完整网页 |
| `src/template.html` | 页面布局、样式与书写逻辑 |
| `src/mapping-editor.js` | 字形筛选、映射、冲突检查与配置管理 |
| `src/runtime.js` | 独立/ATO 保存适配、账号与战役隔离、冲突与临时草稿恢复 |
| `src/host-ui.js` | 模式状态、完整工作备份、主控台/段落导航、Android 文件桥接 |
| `src/glyphs.json` | 内置字形图像数据 |
| `src/parts.json` | 六类部件图像和各字形部件数量 |
| `scripts/build.cjs` | 单文件网页构建脚本 |
| `tests/platform.cjs` | 无浏览器的存储、迁移、冲突、接口与构建测试 |
| `tests/smoke.cjs` | 可选的浏览器功能及响应式布局回归测试 |
| `integration/` | ATO 配套补丁与接入说明（不会自动应用） |

运行测试：

```sh
node scripts/build.cjs
npm test
```

上述测试只需 Node.js，不读取个人浏览器配置，不连接真实 ATO 服务。需要浏览器回归时再运行 `npm install`、`npx playwright install chromium` 和 `npm run test:browser`。可用环境变量 `BROWSER_EXECUTABLE` 指定 Chrome / Chromium，`PLAYWRIGHT_MODULE` 指定已有测试依赖。浏览器测试使用独立临时环境，截图写入忽略的 `tests/qa/`。

## 接入 ATO Assistant

请阅读 [接入说明](integration/README.md)。配套补丁针对本地检查过的 `banard2049-cpu/ATO_assistant` 的 `10dbbf5` 版本；安装前必须先检查能否应用，不要强制覆盖新版本代码。

接入版使用当前 ATO 账号与主控台战役标识保存五个栏位、当前映射、草稿及故事段落来源。保存需要接口返回成功才显示“已同步”。断网时保留按账号/战役区分的临时草稿，允许重试；账号、战役切换或版本冲突时暂停自动写入，可先导出完整工作备份，再重新读取存档。不会自动读取或上传独立版的本机配置。

网页接入、Windows/macOS/Docker 接入沿用现有 PHP 接口；Android APK 通过项目已有的原生接口，并需要配套补丁中的 Java 存档与文件导出适配。未安装接口或缺少素材时，接入版明确提示并停用编辑区，不悄悄降级为独立存档。

## 素材说明

58 个字形与 6 类部件已换用新提供的高清截图素材。字形按原始像素提取，高度约 195–202 像素，保留透明背景与抗锯齿边缘；没有重绘或对旧图进行插值放大。页面按原有显示尺寸缩放，字形编号、部件数量和保存配置格式不变。构建直接使用 `src/glyphs.json`、`src/parts.json`，无需原始截图。

这是非官方爱好者辅助工具，与游戏发行方无隶属关系。游戏名称和相关字形素材的权利归各自权利人所有。本仓库不为第三方素材授予额外使用许可。
